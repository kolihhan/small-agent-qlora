# GAIA100: matched Base, v7 and v8 Step70

This page records what actually ran on November 23, 2026. It does not pool scores across different runtime revisions.

## Experiment

The question was simple: with the same model family, tools, and 100 real tasks, did the trained adapter help the agent finish more work?

The evaluation used:

- GAIA 2023 validation, frozen Evaluation100 from dataset revision 682dd723ee1e1697e00360edccf2366dc8418dd9.
- Exactly 100 tasks: 32 Level 1, 52 Level 2, 16 Level 3. All models received identical task IDs.
- 20 shards of five tasks each. Each shard ran the three available models sequentially on the same GitHub runner.
- Qwen3.5-9B Q4_K_M base GGUF, SHA256 8c4cc24f54473f3d4e080d4ec7fd2a40d0bbec0f94f3c807cd62694905357d54.
- llama.cpp release b11541, SHA256 36ca310be4405acb7ba59b32dbdce32bb9cd7b1ef95358997b7eaed2c6f0188b.
- Context 16,384; temperature 0; reasoning budget 0; 512 new tokens/call; 12 agent steps; four tools (search, read, inspect, python).
- Fixed scorer and evaluator on the experiment branch. No QLoRA training or prompt changes took place during the paired comparison.

The v7 and v8 Step70 GGUF adapters came from [v7 conversion run 43434228699](https://github.com/kolihhan/small-agent-qlora/actions/runs/43434228699) and [verified v8 Step70 conversion run 45037819202](https://github.com/kolihhan/small-agent-qlora/actions/runs/45037819202). Original hashes were checked before inference.

v3D **was not included**: its original Actions artifact had expired. The old v3D result belongs to a different experiment and must not be used as though it were measured here.

## Results

| Metric | Base | v7 | v8 Step70 |
| --- | ---: | ---: | ---: |
| Correct / 100 | 18 | 25 | **29** |
| Emitted a final answer | 47 | 37 | **56** |
| Final answer wrong | 29 | 12 | 27 |
| Invalid final | 38 | 50 | **29** |
| Model error | 7 | 6 | 8 |
| Model timeout | 8 | 7 | 7 |
| Tool calls | 724 | 764 | **546** |
| Tool errors | 38 | 36 | **30** |
| Duplicate-call blocks | 72 | 99 | **41** |
| Mean steps / task | 8.01 | 8.53 | **6.36** |
| Mean wall time / task (s) | 444.7 | 435.9 | **341.1** |

A final answer counts as *completed*, not necessarily *correct*. The GAIA scorer checks whether the final answer matches the expected answer.

The paired transitions are more informative than the headline score:

| Comparison | Newly correct | Previously correct, now wrong | Net |
| --- | ---: | ---: | ---: |
| v7 vs Base | 11 | 4 | +7 |
| v8 Step70 vs Base | 14 | 3 | +11 |
| v8 Step70 vs v7 | 11 | 7 | +4 |

The v8-v7 gain is small enough that a single run cannot establish its stability. The v8-vs-Base result is more encouraging, but it is still only one matched run.

## Where v8 failed

Of its 71 wrong tasks, 27 were completed with a wrong answer, 29 ended with an invalid final, eight with a model error, and seven with a model timeout.

The runtime's last step requests tool_choice="none". Some model responses still contained literal textual tool-call markup instead of a normal final answer. Those are labeled invalid_final. That is a termination/format failure, not proof the correct answer was already available.

A successful tool preflight verified that search, read, inspect and Python were callable on the GitHub runner. It **does not** prove that all relevant evidence was retrieved or understood.

The persistent gap is answer correctness and evidence use. Fixing the final-answer format alone cannot make the 27 wrong completed answers correct.

## Source and caveats

- [Original inference run 45144537782](https://github.com/kolihhan/small-agent-qlora/actions/runs/45144537782): all 20 five-task inference shards completed; the final summary job originally failed because it had not installed the Python package.
- [Recovered summary run 45173486537](https://github.com/kolihhan/small-agent-qlora/actions/runs/45173486537): same 60 saved model/shard result files, no inference rerun. Completed successfully.
- [Download complete scored per-task evidence](https://github.com/kolihhan/small-agent-qlora/actions/runs/45173486537/artifacts/14818152995): includes per-task hashed IDs, outcome, stop reason and paired wins/losses. Raw GAIA questions and reference answers are not published.
- [Experiment branch](https://github.com/kolihhan/small-agent-qlora/tree/exp/gaia-fourway-20261123): evaluation and recovery scripts, weight verification and workflow definitions.
- [Repeatability follow-up](https://github.com/kolihhan/small-agent-qlora/actions/runs/45175648911): independent repeats on the same previously seen cohort. No results are included in this page until that run has a verified complete summary.

A historical [Base/v3B/v3D GAIA100 study](gaia-v3d-results.md) measured 9/100, 18/100, 18/100 under runtime commit 08fbcaa5ed82c5238188c45d5748993bae9bf1e1. The later run changed the runtime (including handling of model reasoning_content). Live web observations can also change. These are plausible confounders; neither is proven to explain the Base difference. **Do not combine old and new scores into one progress curve.**

This is a research validation subset that the project has already examined. It is not a pristine source-disjoint held-out benchmark or an official GAIA leaderboard submission.
